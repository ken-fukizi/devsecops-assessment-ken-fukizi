# Architecture Diagrams

This folder stores architecture visuals used across assessment blocks.

## Structure

- `diagrams/` contains one markdown file per diagram

## Naming convention

- `block-<number>-<topic>.md`

Examples:

- `block-1-multi-scanner-orchestrator.md`
- `block-2-secure-pipeline.md`
- `block-3-container-security.md`
- `block-6-current-state.md`
- `block-6-target-runtime.md`
- `block-6-sdlc-security-controls.md`
- `block-6-trust-boundaries.md`
- `block-6-implementation-roadmap.md`

Block 6 narrative (current state, target, trade-offs, roadmap) lives in [`docs/architecture-design.md`](../architecture-design.md).

## Authoring guideline

- Use Mermaid in fenced code blocks
- Keep each file focused on one architecture view
- Include a short legend and design notes below the diagram
